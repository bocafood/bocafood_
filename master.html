Publicar site

Publica o pacote público completo do site para um tenant específico. Repositório e branch são lidos do cadastro.

Se o campo ficar vazio, o Master usa o token salvo no cadastro da conta. Crie em GitHub → Settings → Developer settings → Personal access tokens (permissão repo).

Publicar todos os sites

Publica o pacote público completo para todos os tenants ativos que têm repositório GitHub configurado no cadastro.

O repositório e a branch de cada tenant são lidos do cadastro (aba Contas). Tenants sem repositório configurado são ignorados.

Google Maps / Places

OpenAI / Próxima Jogada

Configure a chave usada pelo backend para melhorar a leitura das próximas jogadas em Temporadas. A chave não fica no navegador nem aparece depois de salva.

O Master salva a chave em system_private_ai_secrets/default. Em produção, a Function usa primeiro o Secret Manager; se ele não estiver configurado, usa essa chave privada do Firebase.
